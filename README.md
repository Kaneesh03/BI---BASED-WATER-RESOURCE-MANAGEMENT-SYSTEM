# Smart Water Management System

## Project Overview
The Smart Water Management System is a Business Intelligence and Machine Learning based project developed to analyze, monitor, and predict water usage patterns. The project uses Power BI dashboards for visualization and Python-based machine learning models for prediction and analysis.

This system helps in identifying water consumption trends, detecting abnormal usage, and supporting efficient water resource management.

---

## Objectives
- Analyze water consumption data
- Visualize water usage trends using Power BI
- Predict future water demand using Machine Learning
- Improve water resource management
- Support smart city and sustainability initiatives

## How to Run the Project

### Power BI Dashboard
1. Open the `.pbix` file using Microsoft Power BI Desktop.
2. Refresh the dataset if required.
3. Explore the dashboards and visualizations.

### Python Prediction Module
1. Install required libraries:
```bash
pip install -r requirements.txt
```

2. Run the Streamlit application:
```bash
streamlit run app.py
```
